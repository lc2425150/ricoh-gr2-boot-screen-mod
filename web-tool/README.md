# GR II 画面定制 Web 工具

针对**理光 GR II**（固件 `rg2_v003`）的开机画面 / 机身线稿图替换的**浏览器图形界面**。

> 本目录是 `ricoh-gr2-boot-screen-mod` 仓库里的**独立子项目**，与根目录的逆向分析文档、`tools/gr2boot.py` 命令行工具链相互独立，可单独运行。

## 工作原理

GR II 的开机画面是机内资源 `A:/img/dvf_TDSt.brp`，是**未压缩 RGB565 大端帧缓冲**（640×480×2 = 614,400 字节）。因为是等长定长资源，替换时无需改动目录表、无需重算校验和。工具走 SD 卡脚本路径：

1. 生成 `dvf_TDSt.brp` + `Startup.ttl` 放到 SD 卡根目录
2. 相机开机自动执行脚本，用 `filecopy` 覆盖机内画面
3. **不碰固件、零变砖风险**，拔卡即恢复

## 快速开始

```bash
cd web-tool
pip install Pillow          # 唯一依赖
sh start.sh                 # 或 python3 app.py
# 浏览器打开 http://127.0.0.1:8787
```

## 使用步骤

1. 左侧选择「开机画面」或「机身线稿图」
2. 导入你的图片（自动缩放适配 640×480）
3. 点「转换并预览」查看 RGB565 实际效果
4. 下载 **`.brp`** 和 **`Startup.ttl`**
5. 两个文件放到 **SD 卡根目录**，相机正常开机即可自动应用

## ⚠ 首次使用必读：先验证脚本被执行

本方案目前只经**固件静态分析**论证，**尚未实机验证**。首次请：

1. SD 卡根目录只放 `Startup.ttl`（工具生成，含「最小验证脚本」）
2. 相机正常开机，看屏幕是否出现 `STARTUP_TTL_RUNNING`
3. **看到文字** → 路径成立，再启用换图脚本
4. **没反应** → 先排查卡格式（FAT32）/ 文件名 / 卡是否被识别

## 自提原始资源（可选）

仓库**不包含**原始画面文件（理光版权/商标内容）。如需在工具里预览原始画面：

```bash
cd web-tool
python3 ../tools/gr2boot.py extract --outdir assets
```

不提取也不影响核心功能：直接导入你自己的图片即可。

## 安全边界

- 只覆盖 `dvf_TDSt.brp`（开机画面）与 `dvf_key.brp`（机身线稿图）
- **勿动 `dvf_mark.brp`**：那是机身背面 FCC / CE / IC 认证标签，工具已锁定不可编辑
